# 杯中漫游 · Sip Studio

以已确认的 V3「精致高级」视觉开发的 React H5：饮品书、可交互咖啡 / 鸡尾酒工作台、原创配方、本机收藏与饮品卡导出。

## 本地运行

需要 Node.js 20.19+ 或 22.12+，推荐使用当前受支持的 LTS 版本。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。构建与规则验证：

```sh
npm test
npm run build
npm run preview
```

## 已实现

- 8 个咖啡规格、10 款固定鸡尾酒、4 款主理人特调。
- 跟着做、经典挑战和自由调制；原料分类、完整配方与步骤。
- 长按倒入、按量添加、轻倒、搅拌、摇和、打泡、滤出和装饰。
- PixiJS 渲染、低分辨率二维染料流场、规则辅助分层、冰块刚体与自定义浮力。
- 容量限制、配方判定、操作撤销、后台停止倒入、草稿恢复。
- IndexedDB 本机收藏、作品命名、再次调制、PNG 饮品卡导出。
- 手机与桌面布局、画质 / 减少动态效果设置、默认静音。

## 技术边界

当前液体使用 CPU 上的有界二维速度 / 染料场，将结果作为纹理交由 PixiJS / WebGL 绘制；配方控制分层与混合终态。它是可以直接交互的游戏化液体表现，不是精密多相流模拟，也不是预录视频。后续可在保留领域接口的前提下迁移求解器到 GPU。

场景为固定视角 2D / 2.5D 合成。陶瓷杯通过杯口显示液面和奶泡，透明杯通过杯腹展示扩散。完整三维器具、自由拉花、云端账号与公开分享不在当前版本内。

音效目前为程序生成的轻柔倒液循环，AI 音效可按声音制作清单替换。WebGL 无法初始化时提供简化外观回退；高画质与实际手机性能仍需在具体投放设备上继续校准。

## 目录

```text
src/domain/        原料、22个配方、用量与动作规则、测试
src/render/        Pixi 场景、二维流场、Matter 冰块
src/components/    场景适配与原料图形
src/storage/       Dexie 本机数据库
src/App.tsx        饮品书、工作台、成品与收藏
public/assets/     AI 原图、压缩资源与生成记录
scripts/           素材压缩脚本
.openai/           Sites 静态发布配置
```

素材使用内置 imagegen 制作；完整提示词和来源记录在 `public/assets/generation-prompts.json` 与 `ice-generation.json`。原始 PNG 留作可编辑母版，运行时优先加载压缩 WebP。

## 验证范围

Vitest 覆盖全部配方可完成性、容量 / 冰块占位、不同帧率的用量一致性、过滤守恒、关键原料和手法、撤销快照与流场数值稳定性。浏览器验证用于确认长按与精确加料、出杯、收藏与刷新恢复等行为；浏览器模拟不能替代真实手机的性能和内置浏览器适配测试。

## 名称与数据兼容

项目名称为「杯中漫游 · Sip Studio」，包名和代码库建议名为 `sip-studio`。本机数据库与设置保留旧版内部标识，以兼容已有收藏和草稿；历史 AI 素材生成记录保留原始提示词。

## 加料与长按操作

配方步骤和用量作为参考，达到建议用量后仍可继续添加，也不会自动切换原料。冰块可点击加一块，或长按连续添加，数量按杯子剩余容量计算；不足一整块冰的空间仍可加入液体。长按控件在松手、取消、失焦或切到后台时停止，并拦截选字、长按菜单和拖动等浏览器默认行为。
